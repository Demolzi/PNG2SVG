# 主体筛选与非目标元素清除计划

## 1. 问题背景

当前软件已经可以在闭合区域内去除白底或浅色背景，但实际抠图结果中仍可能残留非目标元素。

典型现象：

- 用户画出的闭合区域中包含主要目标和其他杂物。
- 白底背景被去除后，黑色条状物、文字、边框、杂点等仍被保留。
- 这些残留物不是白色背景，因此不会被白底去除算法删除。

因此，当前问题不再只是“背景透明化”，而是需要进一步解决：

> 在闭合区域内识别并保留主要目标，删除不属于主要目标的非目标前景元素。

## 2. 优化目标

在现有“闭合区域 + 白底去除 + 透明导出”的基础上，新增 **主体筛选** 流程。

目标是：

1. 保留用户真正想要的主要目标。
2. 删除闭合区域内的孤立杂物、黑条、文字、边框残留等非目标元素。
3. 避免误删目标的尾巴、手脚、细线、局部纹理等小部件。
4. 保持当前非 AI、轻量级、可打包的技术路线。

## 3. 当前流程与问题

### 3.1 当前流程

```text
用户绘制闭合区域
→ 生成用户区域 mask
→ 边界 Flood Fill 去除白底/浅色背景
→ 得到前景 mask
→ 去小噪点
→ 边缘平滑 / 去白边
→ 输出透明 PNG / SVG
```

### 3.2 当前流程的问题

该流程只能区分：

```text
白色或浅色连通背景 vs 非白色前景
```

但无法区分：

```text
主要目标 vs 非目标杂物
```

所以只要杂物不是白色背景，就会被识别为前景并保留下来。

## 4. 修正后的推荐流程

建议改为：

```text
用户绘制闭合区域
→ 生成用户区域 mask
→ 去除白底/浅色背景
→ 得到初始前景 mask
→ 连通域分析
→ 主体筛选
→ 删除非目标连通域
→ mask 边缘平滑
→ 去白边 / 去色溢出
→ 输出透明 PNG
→ 内嵌 PNG 导出 SVG
```

新增的关键步骤是：

```text
连通域分析 → 主体筛选
```

## 5. 推荐方案一：保留最大连通域

## 5.1 思路

将初始前景 mask 分成多个连通区域，默认认为面积最大的连通区域是主要目标。

处理规则：

```text
前景 mask
→ 找到所有连通域
→ 计算每个连通域面积
→ 保留最大连通域
→ 删除其他连通域
```

## 5.2 优点

- 实现简单。
- 对单主体图片非常有效。
- 能快速删除远离主体的小杂物。
- 不需要新增复杂依赖。

## 5.3 缺点

如果目标本身被分成多个不连续区域，可能误删：

- 尾巴
- 触须
- 手脚
- 细线
- 分离的小部件
- 图标中的独立装饰元素

## 5.4 适用场景

适合：

- 目标主体完整连通。
- 杂物面积较小。
- 一次只抠一个主要物体。

不适合：

- 目标由多个分离部件组成。
- 杂物面积比主体更大。
- 用户需要同时保留多个对象。

## 6. 推荐方案二：保留最大连通域及邻近连通域

这是更推荐的第一版主体筛选方案。

## 6.1 思路

先找到最大连通域作为主目标，然后判断其他连通域是否离主目标足够近。

处理规则：

```text
1. 对前景 mask 做连通域分析。
2. 找到最大连通域，作为主目标。
3. 遍历其他连通域。
4. 如果该连通域面积太小，删除。
5. 如果该连通域距离主目标较近，保留。
6. 如果该连通域距离主目标较远，删除。
```

## 6.2 判断规则建议

### 面积规则

```text
component_area >= min_component_area
```

推荐默认值：

```text
min_component_area = 20 ~ 100 px
```

对于小图，默认 20 px；对于大图，建议按图像面积动态调整。

### 距离规则

```text
component_to_main_distance <= max_keep_distance
```

推荐默认值：

```text
max_keep_distance = 15 ~ 30 px
```

如果图片尺寸较大，可以按 ROI 尺寸动态调整：

```text
max_keep_distance = max(15, min(40, ROI短边 * 0.03))
```

## 6.3 优点

相比“只保留最大连通域”，该方案更稳：

- 可以保留主体附近的小部件。
- 可以删除远离主体的黑条、文字、杂点。
- 对尾巴、手脚、细线等目标附属部分更友好。
- 仍然是非 AI 方案，易实现、易打包。

## 6.4 缺点

如果非目标杂物刚好贴近主体，可能仍会被保留。

后续可以通过“种子点选择目标”进一步解决。

## 7. 推荐方案三：目标种子点选择

## 7.1 思路

让用户在目标主体上点击一个点，软件将该点所在的连通域作为主目标。

流程：

```text
用户绘制闭合区域
→ 用户点击目标主体上的一点
→ 软件生成前景 mask
→ 找到点击点所在连通域
→ 保留该连通域及邻近连通域
→ 删除其他连通域
```

## 7.2 优点

- 比“最大连通域”更准确。
- 当杂物面积比主体大时也能处理。
- 用户只需多点一下，交互成本低。
- 很适合非 AI 抠图工具。

## 7.3 缺点

- 需要新增交互逻辑。
- 需要在 UI 中保存种子点。
- 如果用户点在背景或透明区域，需要提示重新点击。

## 7.4 建议定位

不建议作为第一步实现。

建议作为第二阶段增强功能：

```text
第一阶段：最大连通域 + 邻近连通域
第二阶段：用户点击种子点选择主体
```

## 8. 推荐 UI 参数设计

建议在导出设置中新增一组“主体筛选”参数。

### 8.1 主体筛选模式

```text
主体筛选模式：
[关闭]
[只保留最大连通域]
[保留最大连通域及邻近区域]
[种子点选择主体]
```

第一版建议默认：

```text
保留最大连通域及邻近区域
```

### 8.2 参数建议

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 最小连通域面积 | 30 px | 小于该面积的区域视为噪点 |
| 主体邻近距离 | 20 px | 距离主连通域小于该值的区域保留 |
| 是否只保留最大主体 | 关闭 | 严格模式，可能误删细节 |
| 是否保留邻近小部件 | 开启 | 推荐默认开启 |
| 种子点模式 | 关闭 | 后续增强 |

## 9. 推荐代码结构调整

建议在 `core/mask.py` 中新增主体筛选函数。

### 9.1 新增配置项

```python
@dataclass(frozen=True)
class CutoutOptions:
    feather_radius: float = 1.5
    white_threshold: int = 240
    near_white_tolerance: int = 15
    remove_small_components: bool = True
    min_component_area: int = 20
    keep_largest_component: bool = False

    # 新增
    target_filter_mode: str = "main_with_neighbors"
    main_neighbor_distance: int = 20
    seed_point: tuple[int, int] | None = None
```

### 9.2 主体筛选模式枚举建议

```python
TARGET_FILTER_OFF = "off"
TARGET_FILTER_LARGEST = "largest"
TARGET_FILTER_MAIN_WITH_NEIGHBORS = "main_with_neighbors"
TARGET_FILTER_SEED = "seed"
```

### 9.3 新增函数

```python
def filter_target_components(
    mask: Image.Image,
    options: CutoutOptions,
) -> Image.Image:
    """根据主体筛选策略过滤前景连通域。"""
```

内部步骤：

```text
1. 将 mask 转为 L 模式。
2. 扫描所有 alpha > 0 的像素。
3. 使用 BFS / DFS 计算连通域。
4. 记录每个连通域的像素列表、面积、bbox、质心。
5. 根据模式筛选要保留的连通域。
6. 生成新的 mask。
```

## 10. 连通域距离计算方案

第一版可以使用 bbox 距离，速度快、实现简单。

### 10.1 bbox 距离

每个连通域记录：

```python
bbox = (left, top, right, bottom)
```

两个 bbox 的距离：

```python
def bbox_distance(a, b):
    ax1, ay1, ax2, ay2 = a
    bx1, by1, bx2, by2 = b

    dx = max(bx1 - ax2, ax1 - bx2, 0)
    dy = max(by1 - ay2, ay1 - by2, 0)
    return (dx * dx + dy * dy) ** 0.5
```

如果两个 bbox 接触或重叠，则距离为 0。

## 11. 推荐处理顺序

建议在 `create_cutout_png()` 中使用以下顺序：

```text
1. 生成 user_region_mask
2. 使用 Flood Fill 得到 foreground_mask
3. 结合原图 alpha 得到 combined_alpha
4. 去除极小噪点
5. 主体筛选：保留最大主体及邻近区域
6. mask 形态学平滑
7. alpha 轻微羽化
8. 限制到 user_region_mask 内
9. 去白边 / 去色溢出
10. roi.putalpha(final_alpha)
```

注意：

> 主体筛选应该在边缘平滑和羽化之前完成。

原因是羽化后多个区域可能通过半透明像素粘连，影响连通域判断。

## 12. P0 实施计划

### P0-1：完善连通域分析函数

实现：

```python
def find_connected_components(mask: Image.Image) -> list[Component]
```

每个 Component 包含：

```python
@dataclass
class Component:
    pixels: list[int]
    area: int
    bbox: tuple[int, int, int, int]
    centroid: tuple[float, float]
```

验收标准：

- 能正确统计 mask 中的多个前景块。
- 能返回每个块的面积和 bbox。

### P0-2：实现只保留最大连通域

验收标准：

- 区域内有主体和小杂物时，只保留最大主体。
- 黑条、远离主体的小块会被删除。

### P0-3：实现最大主体 + 邻近区域

验收标准：

- 远离主体的黑条被删除。
- 靠近主体的尾巴、脚、手等细节尽量保留。

### P0-4：接入导出流程

验收标准：

- 导出的 PNG/SVG 不再包含远离主体的非目标元素。
- 背景透明仍然正常。
- 边缘平滑和去白边流程不受破坏。

## 15. 风险与应对

## 15.1 目标部件被误删

风险：尾巴、手脚、细线可能不是最大连通域。

应对：

- 默认使用“最大主体 + 邻近区域”。
- 提供邻近距离参数。
- 后续支持种子点模式。

## 15.2 杂物贴近主体无法删除

风险：如果非目标元素紧贴主体，距离过滤会保留它。

应对：

- 提供更严格的“只保留最大连通域”模式。
- 后续增加手动橡皮擦或种子点模式。

## 15.3 多主体图片误删

风险：用户可能想同时保留多个目标。

应对：

- 提供“关闭主体筛选”模式。
- 建议用户分别画多个闭合区域，每个区域导出一个目标。

## 15.4 细节断裂导致误判

风险：白底去除过强时，主体被分裂成多个块。

应对：

- 主体筛选前可先做轻微闭运算。
- 但不要过度平滑，否则杂物可能和主体粘连。

建议顺序：

```text
轻微闭运算 → 连通域主体筛选 → 边缘平滑
```

## 17. 最终验收标准

完成后应满足：

1. 闭合区域内的白底可以透明化。
2. 闭合区域内远离主体的黑条、文字、孤立杂物可以被删除。
3. 主体本身不被明显破坏。
4. 目标的尾巴、手脚、细线等邻近小部件尽量保留。
5. 用户可以通过参数控制主体筛选强度。
6. 导出的 PNG 和 SVG 背景保持透明。
7. 不依赖 AI 模型。
8. 不显著增加打包难度。

## 19. 一句话结论

当前问题的核心不是白底去除，而是缺少 **主体筛选**。

最推荐的非 AI 解决方案是：

> 对前景 mask 做连通域分析，保留最大主体及其邻近连通域，删除远离主体的非目标元素。
